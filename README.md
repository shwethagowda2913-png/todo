# 📝 To-Do List App

A simple and interactive To-Do List application that helps users manage their daily tasks efficiently.

## 🚀 Features

- **Add Tasks:** Create new tasks.
- **View Tasks:** Display all added tasks.
- **Edit Tasks:** Update existing tasks.
- **Delete Tasks:** Remove tasks when completed or no longer needed.
- **Simple UI:** Clean and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure


## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/shwethagowda2913-png/todo.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start managing your tasks!
